# Security Policy

## Supported Versions

We provide security updates for the latest release of `surge`.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `surge`, please send an email to **Jad Madi** at [jadmadi@duck.com](mailto:jadmadi@duck.com).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof of concept.
- Any suggested fixes or mitigations.

You will receive an acknowledgment within 48 hours. Please do not open public GitHub issues for security vulnerabilities until they have been reviewed and addressed.

## Legal and Ethical Usage Notice

`surge` is designed for testing systems, websites, and APIs that you own or have obtained explicit written authorization to test.

Unauthorized load testing may degrade third-party services and violate laws such as the **Computer Fraud and Abuse Act (CFAA)** in the United States, the **Computer Misuse Act 1990** in the UK, and equivalent statutes internationally. Maintainers disclaim any liability for unauthorized or unlawful use.
